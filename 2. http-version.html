HTTP itu selalu berkembang. Saat ini, kebanyakan web berjalan di HTTP/1.1 atau HTTP2 HTTP2 mulai hadir sekitar tahun 2015, dan saat ini sudah banyak diadopsi oleh semua Web di dunia Saat ini, HTTP/1.1 merupakan fallback protocol (kalau versi HTTP/2 tidak support, maka akan menggunakan HTTP/1.1), dimana secara default Web Browser akan melakukan request menggunakan HTTP/2, jika web server tidak mendukung, maka Web Browser akan melakukan fallback ke protocol HTTP/1.1 Secara garis besar, HTTP/2 sama dengan HTTP/1.1, yang membedakan adalah pada HTTP/2, HTTP Request yang dikirim dalam bentuk teks, secara otomatis akan menjadi binary, sehingga lebih cepat dibandingkan HTTP/1.1 Selain itu, HTTP/2 menggunakan algoritma kompresi untuk memperkecil request dan mendukung multiplexing, sehingga bisa mengirim beberapa request dalam satu connection yang sama Dari sisi pembuatan aplikasi, tidak ada perbedaan, semua ini biasanya sudah diurus secara otomatis oleh Web Server yang kita gunakan
