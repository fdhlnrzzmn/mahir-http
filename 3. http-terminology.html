Saat belajar HTTP, banyak Terminology (istilah) yang perlu kita ketahui Merupakan aplikasi yang digunakan untuk mengakses Web menggunakan protocol HTTP, contohnya Google Chrome, Brave, Safari, Mozilla Firefox, Microsoft Edge, Opera, Duck Duck Go, dan lain-lain Transmission Control Procotol, adalah salah satu protocol dalam jaringan komputer yang biasa digunakan oleh Web, Email, FTP, atau lainnya Jika kita menggunakan jaringan internet, kemungkinan besar kita akan menggunakan protocol TCP untuk melakukan koneksi jaringannya Internet Protocol digunakan sebagai identitas komputer di jaringan, saat kita terkoneksi ke internet, pasti kita punya IP Setiap komputer, baik itu Client maupun Server akan memiliki IP Cara cek-nya, bisa melalui web https://whatismyipaddress.com/ Uniform Resource Locator, merupakan alamat dari sebuah Resource di Web, misalnya https://fdhlnrzzmn.com, saat kita mengakses URL ini, maka sebenarnya akan mengarah ke IP Adress-nya Domain Name Server, merupakan tempat yang berisi data katalog pemetaan antara nama domain di URL menuju lokasi IP komputer Sebenarnya, saat mengakses web melalui domain, itu akan mengakses IP-nya, tapi karena sulit untuk mengingat IP yang berupa angka, maka diganti menggunakan nama domain di URL Jadi, Saat Web Browser mengakses sebuah domain di web, sebenarnya prosesnya, Web Browser akan bertanya ke DNS untuk mengetahui berapa alamat IP domain web ini, lalu DNS akan memberitahu IP-nya, lalu Web Browser akan melakukan Request ke IP tersebut dan akan menampilkan isi Web-nya Untuk memeriksa IP Domain, kita bisa gunakan web https://www.whatismyip.com/dns-lookup/ Web Server adalah aplikasi yang berjalan di jaringan internet yang bertugas sebagai server Web Server berisi informasi dan data yang biasa diakses oleh Client Web Server akan menerika Request dari Client, dan membalas Request tersebut dengan informasi yang diminta oleh Client
