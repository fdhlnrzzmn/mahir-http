Untuk memaksa Client untuk melakukan Redirect ke halaman lain, kita bisa menggunakan HTTP Redirect dengan Status Code 300 - 399 Lantas, dari mana Client tahu harus melakukan Redirect ke URL mana? Oleh karena itu, biasanya Response HTTP Status Code yang Redirect selalu dibarengi dengan informasi URL Redirect-nya, dan itu disimpan pada HTTP Response pada Header Location, letaknya di bawah Start Line Contoh : HTTP/1.1 301 Location : /dashboard (ini kalau Redirect-nya berada di domain yang sama, tinggal ketikkan Path-nya) Location : https://www.fdhlnrzzmn.com (Kalau beda domain, langsung arahkan ke domain tujuan Redirect-nya)
