HTTP adalah singkatan Hypertext Transfer Protocol HTTP merupakan protokol untuk melakukan transmisi hypermedia document, seperti HTML, Javascript, CSS, Image, Audio, Video, dan lain-lain HTTP awalnya didesain untuk komunikasi antara Web Browser dan Web Server, namun saat ini sering juga digunakan untuk kebutuhan lain. HTTP mengikuti arsitektur Client dan Server Client mengirimkan HTTP Request untuk meminta atau mengirim informasi ke server Server membalasnya dengan HTTP Response dari HTTP Request yang diterima HTTP didesain menggunakan bahasa yang mudah dimengerti oleh bahasa manusia, seperti : - GET (Ambil) - POST (Kirim) - PUT (Ubah) - DELETE (Hapus) - HEAD - OPTION HTTP itu protokol yang stateless Stateless itu artinya, HTTP Request merupakan Request yang independen, tidak ada keterkaitan atau hubungan dengan HTTP Request sebelum atau sesudahnya Hal ini dilakukan agar HTTP Request tidak harus dilakukan dalam sequence (berurutan), sehingga client bisa melakukan HTTP Request secara bebas tanpa ada aturan harus dimulai dari mana, misalnya web, entah dibuka dari halaman lain, halaman beranda, atau profil, semuanya bisa terakses, tidak harus berurutan harus dibuka berurutan melalui halaman tertentu Jika HTTP itu stateless, lantas bagaimana dengan Session? misalnya saat ingin membuka halaman beranda Facebook, harus ke halaman login terlebih dahulu jika belum ter-login. Untuk menangani ini, HTTP punya fitur HTTP Cookie, yang dimana fitur ini memaksa Client menyimpan informasi yang diberikan oleh Server
